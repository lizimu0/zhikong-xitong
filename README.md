# 医疗文书智能质控系统

基于卫健委《卫生健康行业人工智能应用场景参考指引》第28条场景设计的出院病历智能质控后台 Demo。

## 项目简介

本系统面向三甲医院病案管理科，利用 AI 技术对出院病历进行自动化质量控制，覆盖病历完整性、逻辑一致性、术语规范性等多维度检查，辅助质控人员高效完成病历审核工作。

## 技术选型

- **HAPI FHIR** (Apache 2.0) — 医疗数据标准化引擎
- **AppSmith** (Apache 2.0) — 低代码后台框架
- **NLP 质控引擎** — 病历文本智能分析
